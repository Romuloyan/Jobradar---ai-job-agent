# Candidate profile example

This file is a template. Copy it to `candidate_profile.md` and replace the example content with the real candidate profile.

`candidate_profile.md` is ignored by Git because it may contain personal data.

## Purpose

This profile is used by the JobRadar agent to evaluate job vacancies. It is not a full CV. It should be realistic, precise and honest.

## Professional goal

The candidate is looking for an entry-level or transition role in Electrical and Computer Engineering, preferably in Portugal, hybrid or remote, with opportunities to learn through practical work.

## Target areas

- Electrical engineering
- Electrical installations and project support
- Site supervision and construction support
- Automation and control systems
- Energy and efficiency
- Technical support and field engineering
- Data centres and infrastructure
- IoT, hardware and systems integration
- AI-assisted automation and productivity tools

## Education

- Degree in Electrical and Computer Engineering.
- Academic background in systems, electronics, control, telecommunications, energy, programming and engineering documentation.

## Technical skills

- MATLAB: academic and project experience.
- Python: basic to intermediate practical usage.
- C: academic foundations.
- Excel: formulas, filters, tables, charts and data validation.
- GitHub and VS Code: basic project workflow.
- Generative AI: technical research, code review support, documentation support and prototyping.

## Skills currently being developed

- AutoCAD
- Revit
- PLC / SCADA fundamentals
- Python automation
- LLM API integration

## Professional strengths

- Communication
- Organisation
- Training and teaching experience
- Client-facing experience
- Documentation
- Practical troubleshooting
- Responsibility and autonomy

## Constraints

- Prefer roles in Lisbon or remote/hybrid roles compatible with Portugal.
- International remote roles may be considered.
- Occasional travel is acceptable.

## Evaluation rules

The agent should:

- Avoid exaggerating the candidate's technical experience.
- Distinguish general professional experience from formal engineering experience.
- Prefer realistic entry-level, junior, trainee, assistant or transition roles.
- Penalise senior roles requiring several years of direct engineering experience.
- Penalise roles requiring advanced AutoCAD, Revit, PLC, SCADA, cloud or software engineering expertise if those are core mandatory requirements.
- Highlight when a role is worth applying to despite missing some skills.
